# Doklo Studio Demo — 사용자 가이드

처음 사용하는 분을 위한 안내서입니다. 4단계로 한 번 둘러보세요.

## 1. 로그인

Google, Apple, Kakao 중 하나를 선택해 한 번에 로그인할 수 있어요. 처음 로그인하면 자동으로 프로필이 만들어집니다.

- 이미 다른 공급자로 가입된 계정이 있다면 **자동으로 통합**됩니다
- 로그아웃 후 다시 같은 공급자로 로그인하면 기존 세션이 복구됩니다

## 2. 장바구니에 담기

상품 상세 화면에서 **장바구니** 버튼을 누르면 헤더 카운트가 올라가고 토스트 알림이 표시됩니다.

수량은 장바구니에서 자유롭게 조정 가능합니다. 단일 상품 수량은 `99개`를 초과할 수 없어요.

## 3. 결제

결제 화면에서 카드, 계좌이체, 간편결제 중 선택할 수 있어요.

1. 결제 수단을 선택합니다
2. 결제 정보를 입력합니다 (실시간 검증)
3. 결제 게이트웨이의 응답을 기다립니다
4. 완료 화면에서 주문 번호와 영수증을 확인합니다

> 결제 금액은 최소 1,000원 이상이어야 하며, 입력한 결제 정보는 응답 직후 폐기됩니다.

## 4. 주문 내역

최근 3개월의 주문이 시간 역순으로 표시됩니다. 그 이전 주문은 **전체 보기**를 통해 확인할 수 있어요.

각 주문의 상세 화면에서 영수증 다운로드, 배송 상태 확인이 가능합니다.
