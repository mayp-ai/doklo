# Doklo 개발자 프리뷰

지원되는 앱 코드를 읽어 기능 문서 초안을 만들고 사람이 검토하는 로컬 도구입니다. Apache-2.0 CLI, 검토용 웹 UI, 읽기 전용 MCP 서버를 제공합니다.

## 설치

```bash
npm install -g @mayp/doklo@preview
```

Node.js 20.9 이상이 필요합니다. 현재 Next.js App Router와 작업 공간당 프로젝트 하나를 지원합니다. 출시 수용 검증 범위는 BTV 업로드 기능이며, 다양한 프레임워크 지원이나 AI 답변 품질 향상은 입증하지 않았습니다.

## 프로젝트에서 시작하기

```bash
doklo init
doklo generate
doklo serve --open
doklo sync --check
```

초기화가 모델·브랜치 선택을 기록하고 프로젝트를 스캔한 뒤 다음 명령을 안내합니다. 생성 전에 전송할 소스와 모델 경로를 확인해 주세요. 선택한 소스 발췌가 해당 모델 공급자에게 전송될 수 있으며 모델 이용 비용은 별도입니다. 생성 결과는 초안이고, 사람이 로컬 웹에서 검토한 뒤 active로 전환합니다.

명령 옵션은 `doklo --help` 또는 `doklo <command> --help`로 확인할 수 있습니다. 에이전트는 프로젝트 루트를 명시해 `doklo mcp`로 연결합니다. 설치 패키지의 `AGENT_GUIDE.md`에 에이전트 안내가 포함됩니다.

## 알려진 한계

- 정적 import 추적에는 깊이 제한이 있습니다. 동적 import·런타임 연결은 누락될 수 있습니다. 미해결 내부 import는 스캔을 중단합니다.
- 이전 추적 정보는 복구·검토 전까지 unknown입니다. `doklo scan --repair-tracking`은 본문·이력을 유지하면서 추적 정보를 복구하며, 이후에도 사람 검토가 필요합니다.
- fresh는 추적 소스 해시가 같다는 뜻으로 문서 정확성·완전성을 보증하지 않습니다.
- 일반 sync는 사람이 편집한 문서를 건너뛰어 보존합니다. 강제 재생성 시 자동 병합은 검증하지 않았습니다.
- 키 없는 Claude Code 경로는 generate에만 제공됩니다. sync에서도 지원한다고 가정하거나 공급자를 임의로 바꾸지 마세요.
- 논의 중인 로컬 Live Review 연동은 이번 프리뷰에 포함되지 않습니다.
